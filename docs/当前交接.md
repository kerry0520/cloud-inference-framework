## 本轮结论（可直接引用）

- **远程操作的可行方式**：我在 WSL 里用 OpenSSH 9.6 非交互地 `ssh` 到租用机（已确认存在）+ `rsync`
  回传结果。用户只需给 `host`/`port` 并把公钥贴进实例的 `~/.ssh/authorized_keys`；**密码不需要**，
  也不该出现在聊天里。代码从 public 仓库 clone，权重由 `modelscope`（失败回退 `HF_ENDPOINT=hf-mirror`）
  下载，无需上传任何本地大文件或凭据。
- **平台建议**：先 AutoDL（人民币、便宜、镜像多），开机第一件事 `nvidia-smi` 看驱动。
  驱动 ≥580 → 全量 `repro_l4.sh`；<580 → `--torch-only` 只跑 `quant-probe`/`minp-sweep`/`minp-compare`
  三个 torch/Triton 阶段（恰好是"内核结论换硬件"最关键的部分）。要全量端到端又不想折腾驱动，
  用 RunPod L4 或阿里云/腾讯云新驱动镜像。费用量级：环境 15–25 分钟 + 实验约 63 分钟，
  AutoDL 约 ¥4–6，RunPod L4 约 $1–1.5（以控制台为准，我不代下单）。
- **已验证**：`remote_bootstrap.sh` 的 `--facts-only` 在本机 WSL 跑通（`driver=617.42`、
  `RTX 5060 Laptop`、`python=3.12.3`，产出 `facts.txt`/`report.env`）；四个 shell 脚本 `bash -n` 通过、
  CR=0。**未验证**：真实租用机上的完整安装路径（首次会在 `--facts-only` 与 `--dry-run` 之后才跑全量）。
- 结论边界不变：单卡、单模型、未锁频、合成 prompt；绝对数字不可外推，可外推的是比例与机制。
