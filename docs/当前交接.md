  −1.58 [−1.82, −1.51]、−1.10 [−1.37, −0.85]、−1.21 [−1.52, −0.68]。三个区间都排除 0。

  → 预期 1.18%，实测 1.10% [0.85, 1.37] 重合。局部 8.9× 与整请求 1% 是同一个分母。

  `_min_p_kernel 0`、`_min_p_partial_max 3107`、`_min_p_apply_threshold 3107`。
- **采样 id 不可复现**：同一 arm 的两次相同调用在 batch4 也会差 1 个 token（此前跨臂断言因此失败）；
  base 臂 44/48、patched 臂 47/48 与首个 base 相同，首个分歧都在第 3 个 token，两臂幅度相当。
  token id 只能作旁证；数值等价以第四阶段的 filtered-logits 逐字节一致为准。

  qkv −0.6%、o_proj −8.2%、gate_up +4.6%、down_proj −12.8%、lm_head +9.7%（`lm_head` 未参与自己的拟合，
  且在 CUDA 图外）。standalone 流带宽 322–347 GB/s 与引擎内 375 GB/s 的矛盾仍未解释（未锁频、nvidia-smi 采样不可用）。
