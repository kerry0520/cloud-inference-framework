## 本轮结论（可直接引用）

- **第二轮复现**（`results/abba-scale-20261018T035002Z`，EXIT=0，新引擎会话、batch 1/2/4/8）：
  decode Δ% 中位与 95% CI 为 batch1 −1.23 [−1.61, −0.88]、batch2 −1.00 [−1.21, −0.82]、
  batch4 −0.81 [−2.53, −0.46]、batch8 −0.91 [−1.55, −0.75]；**四个区间全部排除 0**。
  wall Δ% 为 −1.17、−0.42 [−1.33, +0.11]、−0.61、−0.69，batch2 含 0（wall 噪声底更高）。
- **分子是常数、分母在变**：run A（10-17）节省 75.0 / 53.7 / 58.0 µs，run B（10-18）
  53.8 / 45.7 / 69.2 / 54.9 µs；两轮平均 62.2 / 55.9 µs，与 profiler 推得的 56.9 µs 同量级。
  decode 步 run A 4.49–5.13 ms、run B 4.29–4.95 ms，所以百分比从 −1.2% 稀释到 −0.91%；
  模型预测 −1.32 / −1.27 / −1.19 / −1.15%（固定 56.9 µs ÷ 步长），实测同向且多数落在 CI 内。
- **第一轮结论不变**（`results/abba-20261017T103216Z`）：24 轮 ABBA，decode Δ% batch1/2/4 =
  −1.58 [−1.82, −1.51]、−1.10 [−1.37, −0.85]、−1.21 [−1.52, −0.68]；上限一致性
  `(62.5−5.6)/4812 = 1.18%` 对实测 1.10% [0.85, 1.37]。
- 派发证明（两轮一致）：patched 臂 `_min_p_kernel 0`、`_min_p_partial_max`/`_min_p_apply_threshold`
  与真实调用次数同量级（run A batch2：3107/3107，6073 次 batch2 调用）。
- 采样 id 仍只作旁证（run B 一致率 48/48、48/48、47/47、48/48；同一 arm 也会漂移，见第五阶段）。
- 结论边界：单机 RTX 5060 Laptop 8 GB、单模型、batch ≤ 8、只测 `min_p = 0.1`；
  跨会话绝对值不可比（run B 的 decode 步快约 4%），百分比只在同一会话配对内解释。
