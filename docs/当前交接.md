## 本轮结论

- 内核级（V151936，逐字节一致）：**同一 8192/16 启动参数下**，per-lane 归约比上游 per-tile 快 1.25–1.31×（b1 18.7→14.4、b8 20.6→15.7 µs）。作者 A100 是 1.26× ——方向与量级独立复现。
- PR 合并启动参数后相对上游：fp16 4.58×/3.99×/3.94×/4.30×/4.03×/2.69×/1.65×（batch 1–64）；fp32 3.71×/2.79×/2.73×/2.76×/2.68×/1.63×/1.17×。
- batch 64 上不单调：fp16 我们的 16384/16 旋钮更快（41.2 vs 45.2 µs），fp32 则 PR 更快（163.4 vs 224.0 µs）。不能把单一 batch 的胜负外推。
- 引擎级（同进程两臂常驻、轮级配对）：decode Δ% batch 8 **−0.60…−0.85%**、batch 32 **−0.81…−1.17%**、batch 2 −0.61%。作者的 −2.72%/−2.43% 没有被复现成同一个数字，原因是分母（本机 decode 步约 4.79 ms）与 harness 不同；这一点已写进文档与评论，不当作对方有错。
- 派发形态发现：MRV2 把采样拆成**每 8 行一组**调内核（batch 32 的 24,960 次里有 24,192 次是 `(8, 151936)`），所以 PR 的 `num_tokens <= 32` 分支比实际行数宽；这一点已作为观察写入上游评论。
- 单次运行不足：第一次 16 轮在 batch 32 上遇到一轮整轮漂移（CI 拉到 ±10%），24 轮后才收窄到 ±1.6%；batch 2 在第二轮反而更抖（±3.4%）。
