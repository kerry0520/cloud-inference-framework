## 本轮结论（可直接引用）

- **两行旋钮的内核收益**（`results/minp-sweep-20261018T051134Z`，fp16、`min_p=0.1`、全部逐字节相同）：
  V151936 batch 1/2/4/8 上游 66.5/66.5/66.3/67.9 µs → 15.9/18.6/18.7/18.5 µs = **4.18×/3.57×/3.55×/3.67×**；
  batch 32/64/256 为 2.49×/1.80×/1.18×（不退化）；V32000 batch 1–8 为 1.02–1.07×（持平），
  32/64/256 为 1.29×/1.33×/1.17×。
- **引擎内配对**（`results/abba-knob-20261018T051230Z`，24 轮 ABBA/BAAB，batch 1/2/4/8）：
  decode Δ% = −0.77 [−1.20, −0.21]、−0.80 [−1.29, −0.41]、−0.78 [−0.88, −0.13]、−0.80 [−0.92, −0.56]；
  wall Δ% = −0.71 [−1.34, −0.20]、−0.53 [−1.59, +0.36]、−0.76 [−0.96, −0.09]、−0.65 [−0.81, −0.38]；
  wall 中位 289.1→287.1、314.7→313.1、330.2→329.4、354.7→353.0 ms。
  派发证明：patched 臂 `_min_p_kernel = 3120`（batch8），两个两阶段内核均为 0。
- **对比**：旋钮版拿到两阶段版的约 2/3–3/4 端到端收益（两阶段 run A decode −1.58/−1.10/−1.21，
  run B −1.23/−1.00/−0.81/−0.91），而改动只有 2 行、无派发、无回退风险。
- **上游可行性判断**（详见评估文档）：issue-first 成功率高（>80% 能发出去，30–40% 有实质回复）；
  直接提 147 行两阶段 PR 被合并概率 ≤15%；提"两行 + pytest + benchmark + 数据中心卡数据"约 30–45%。
  最大障碍不是技术，而是 vLLM 的 AI 贡献政策（禁止纯 agent PR、必须披露、人负责）与审阅带宽。
- 结论边界：单机 RTX 5060 Laptop、未锁频、只测 Qwen3-0.6B 与 `min_p=0.1`；
  旋钮在 A100/H100/L4 上的表现未知，不能外推。
