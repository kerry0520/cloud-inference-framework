```powershell
wsl -d Ubuntu-24.04 -- bash /mnt/c/Users/32065/Documents/ChatGPT/云端推理框架/scripts/setup_cuda.sh
wsl -d Ubuntu-24.04 -- bash /mnt/c/Users/32065/Documents/ChatGPT/云端推理框架/scripts/preflight.sh

```

按顺序执行，前一项成功后再继续，不并发执行 GPU 实验。入口为每轮创建新目录并记录退出码，完成后复制到 Windows results/。若外部中断导致未复制，可从 WSL 同名目录恢复；没有最终退出码不能计为通过。

`setup_cuda.sh` 只在本项目的 `cuda-toolkit/` 下建立编译器、头文件、运行库和 WSL 驱动库链接，适配 pip 包的目录布局。它不安装或覆盖显卡驱动。入口也把虚拟环境的 Ninja 加入 PATH。

WSL2 下显式设置 `VLLM_WSL2_ENABLE_PIN_MEMORY=1`；这是上游现成配置。小规模复制与采样检查只验证对应路径，不宣称所有内存模式均兼容。

  -c /mnt/c/Users/32065/Documents/ChatGPT/云端推理框架/configs/compiler-constraints.txt

完整依赖以最终环境快照为准。上述过程尚未在第二台机器独立从零验收。

模型下载使用固定 revision 的官方文件，脚本逐项计算 SHA256；普通文件另核 Git blob，LFS 权重核上游 SHA256。WSL 下载停滞时曾通过 Windows 同一官方地址补齐词表；元数据与原始失败日志保留。下载器缓存元数据目前使用本轮 bootstrap 路径，是首轮工具，尚非通用发行工具。

## 基线含义

每请求输入 128 个固定有效 ID，输出固定 128 token；greedy，忽略自然 EOS，仅用于合成性能负载。batch 1/2/4/8，每组一轮预热、三轮测量。FP16，上下文上限 2048，并发上限 8，prefix caching 关闭以避免重复输入缓存混淆，异步与 CUDA Graph 保留默认优化。

批次 wall 包含 prefill 与引擎处理，不是纯 Decode；总输出吞吐也不是单请求出字速度。若返回的引擎时间戳有效，另计算首末 token 之间的平均间隔。重复 greedy token 一致仅证明有限生成轨迹复现，不等于完整 logits 或任务质量验收。

profile 是独立进程，只采 batch 2、短输出；延后四步启动并限制采集步数，以优先观察 Decode。实际阶段需检查 trace 标注。带 profiler 的耗时不能当正式性能结果。
